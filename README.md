# My Blessed Reset

A free, static web app from The Blessed Reset Radio. Pick an angel number, hear the song, read the affirmation and write a short journal line.

- No server, no accounts. Check-ins are saved in the visitor's own browser only.
- Songs play through YouTube embeds. Full-quality downloads are part of the paid pack on Stan, not this repo.
- Host with GitHub Pages: Settings > Pages > Deploy from branch > main / root.

For encouragement and reflection. No specific results are promised. Songs and visuals were created with AI tools.
